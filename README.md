# Joker 個人化思考決策 Skill

## 這是什麼

這是一套根據 Joker 的思考決策資料庫整理而成的個人化 Skill。它包含 76 個思考習慣、45 份情境決策報告，以及問題路由、證據分級、最小驗證、停損條件與流程化執行規則。

它的核心不是要求每次回答都變長，而是讓回答在需要分析或做決策時，優先遵循以下主鏈：

> **目的與問題定義 → 現況／目標／限制 → 拆解變數與利害關係人 → 證據品質與不確定性 → 候選方案與效用取捨 → 最小可逆驗證 → 擴大、修正或停損 → 留下可重用流程。**

## 安裝方式

### 方式一：直接加入個人 Skills

在本次回覆的 Skill 附件卡片中，先預覽 `SKILL.md`，確認名稱為 **Joker 個人化思考決策協作 Skill**。確認內容後，選擇 **Add to My Skills**，即可將整個 Skill 加入個人 Skills。

安裝完成後，新的對話可以依問題內容觸發此 Skill。當問題涉及分析、規劃、選擇、風險、複雜問題、工具導入、資源分配、說服、溝通或停損時，Skill 會進入標準或深度模式；簡單問答、翻譯、摘要與格式處理則維持輕量回答。

### 方式二：先下載，再自行保存或安裝

在附件卡片中選擇 **Download**，下載 Skill 套件。建議將下載檔案命名為：

```text
joker-thinking-decision-toolkit.skill
```

請保留這個 `.skill` 檔案，因為它包含 `SKILL.md` 與所有必要的參照資料。若你的 Skills 管理介面提供 **Import、Upload 或 Add Skill** 功能，選取這個 `.skill` 檔案即可匯入；若介面沒有匯入按鈕，則可保留下載檔案，之後直接使用附件中的 `SKILL.md` 重新加入。

## 如何讓每個 Turn 都依據 Joker 的思考習慣

Skill 的完整參照資料採用按需載入，不建議每個 Turn 都讀取全部 45 份報告與 76 個習慣。若希望每一個 Turn 都先做一次 Joker 式的思考校準，請將 `every_turn_protocol.md` 的內容複製到個人或專案層級的固定指示中。

固定指示建議使用以下短版：

> 請先用輕量方式檢查：Joker 真正要完成什麼？目前最重要的限制、證據與不可接受代價是什麼？這次是否需要澄清、查證或先做小型驗證？若只是簡單問答、翻譯、摘要或格式處理，直接回答，不要硬套完整框架。若涉及分析、規劃、選擇、風險、工具、資源、溝通或重要行動，依序先定義真正問題，再拆解限制與利害關係人，區分事實／推論／假設，挑選最必要的 1–3 個思考習慣，提出可執行的下一步與停損條件。不要把推論說成事實，不要把所有問題複雜化，也不要把最終價值判斷與責任外包給工具。

這段短版協定的作用是「每個 Turn 先校準」；完整 Skill 的作用則是「遇到複雜問題時，深入選報告、執行流程與檢查停損」。兩者搭配，比每次都強制輸出完整分析更穩定。

## 如何確認 Skill 有正確套用

安裝後，可以用以下測試提示驗證：

```text
請用 Joker 的思考決策框架，分析我是否要導入一個新工具。
目前目標是＿＿＿＿，限制是＿＿＿＿，已知證據是＿＿＿＿，可接受代價是＿＿＿＿。
請先重述真正問題，再選 1–3 個最接近的決策報告，列出每一步的問題、產出、進入判準，以及停損條件。
```

正常套用時，回答應該能看見下列特徵：它不會直接跳到工具推薦；會先釐清目標、限制、證據與代價；會說明採用哪些思考習慣或決策報告；會區分事實、推論、假設與建議；會提出最小可逆驗證；最後會給出擴大、修正或停止的條件。

如果只是問「這個詞是什麼意思」或要求翻譯，正常結果應該是直接回答，而不是產生完整的決策報告。這代表輕量模式正在避免過度套用框架。

## 使用時的建議

第一，先用 5–10 個真實任務測試，不要一開始就修改大量規則。建議涵蓋工作規劃、資料查核、工具導入、資源取捨、人際溝通與是否停損等不同類型。

第二，觀察三件事：配對的報告是否命中、追問是否真的改變決策、停損條件是否具體有用。若簡單問題變得太冗長，應收窄觸發範圍；若複雜問題仍然過於通用，應補充對應案例或增加更精確的路由訊號。

第三，不要把 Skill 當成固定答案產生器。資料庫中的部分習慣是「推論」或「待驗證」，而不是已經證明的普遍定律。新的實際使用經驗應該用來修正框架，而不是被框架壓過去。

## 下載與備份建議

建議至少保存兩份：一份是可安裝的 `.skill` 套件，另一份是完整的原始資料庫壓縮檔。若要自行維護版本，請同時保留 `SKILL.md`、`every_turn_protocol.md`、`report_index.md` 與 `references/reports/`，不要只保存主檔，否則 Skill 會失去完整的 45 份報告與習慣清單。

# 認識笛卡兒：一輩子所學的知識可能都是錯的

來源：超級歪的哲學訓練課！帶你破解人性盲點，養成邏輯腦｜第 3 章・單元 2｜原始逐字稿未收錄於本 repo

## 精華摘要

- 本章導入笛卡兒的問題：若傳統知識可能被新發現推翻，能否找到更穩固的知識基礎？
- 講師以笛卡兒的耶穌會教育、形上學問題、數學與晚年瑞典經歷作背景，說明他面對既有知識權威時的思考脈絡。
- 這些歷史敘述中包含推測性死因（肺炎或砷中毒）與哲學史概括；逐字稿未提供來源，應視為課程背景說明，不能直接當作已查證史實。

## 關鍵概念

- **知識基礎問題**：一個信念被廣泛接受，不等於它沒有可疑前提；要追問它依賴什麼理由與來源。
- **形上學**：課程用來指探討存在、自由意志、心靈與根本原因等問題；此類問題可能超出單一自然科學方法可直接回答的範圍。
- **理性與數學**：講師以笛卡兒對數學確定性的重視作為章節引子；後續需要區分數學推演的確定性與經驗事實的可修正性。
- **歷史推測需分層**：能確定的傳記資料、學者假說與講師的戲劇化敘述應分開記錄。

## 可複製的行動／能力

**適用情境：**遇到「大家都這樣說」、教科書／權威來源或長期深信的知識時。

1. 把信念改寫成精確主張，避免只寫「這是常識」。
2. 回溯它來自哪個人、研究、制度或資料；查找原始來源與發布時間。
3. 區分定義／邏輯推論、觀察資料、解釋模型與價值判斷。
4. 列出可能推翻或限制主張的反例、新證據或適用條件。
5. 暫時保留、降低信心或修正結論，並註記何時需重新檢查。

**成果檢查：**能說明信念的依據與可修正條件；不因作者有名或歷史故事生動就跳過查證。

## 核心概念延伸

【一般策略／推論】建立信念來源鏈：主張 → 最初來源 → 轉述／摘要層數 → 資料類型 → 可推翻條件。轉述層數越多、來源越不透明，信心越應保留；遇到專業或高影響資訊，優先回到原始研究／文件。

## Notion 行動卡

- **情境：**挑一個你經常引用、但不記得來源的「常識」。
- **下一步：**追到一個原始來源，標註其主張、範圍與限制。
- **完成證據：**來源鏈、原始連結、反例／限制及更新後的信心。
- **回顧問題：**我相信的是原始證據，還是經過多次轉述的故事？

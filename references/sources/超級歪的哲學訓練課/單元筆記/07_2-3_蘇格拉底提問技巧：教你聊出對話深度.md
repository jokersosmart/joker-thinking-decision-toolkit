# 蘇格拉底提問技巧：教你聊出對話深度

來源：超級歪的哲學訓練課！帶你破解人性盲點，養成邏輯腦｜第 2 章・單元 3｜原始逐字稿未收錄於本 repo

## 精華摘要

- 蘇格拉底式提問不以快速給答案或擊敗對方為目標，而是先承認自己可能不懂、善意理解對方，再透過追問讓概念更清楚。
- 本單元整理四個技巧：從例子上升到概念、提出反例、用反詰檢驗論點是否矛盾、用聽眾熟悉的類比說明抽象概念。
- 對話可能沒有終極定義，但能讓參與者發現原本的定義不足，並更精確地看見價值預設。

## 關鍵概念

- **例子與概念不同**：某個勇敢行為是例子，不一定涵蓋「勇敢」的完整定義；從例子抽取共通特徵，才進入概念討論。
- **反例校準範圍**：若定義把不相關或不想納入的情況也算進去，反例可以暴露定義過寬或過窄；反例要貼近對方原意。
- **反詰檢查一致性**：用對方可能接受的另一項主張檢查前後是否衝突；須先確認重述準確，否則只是製造矛盾。
- **類比幫助理解但不等於證明**：類比要選受眾熟悉的情境，並檢查兩個案例有哪些相似與重要差異。
- **謙遜與善意**：把批判對準主張，不醜化對方；目標是共同澄清，而非用提問包裝攻擊。

## 可複製的行動／能力

**適用情境：**價值詞引發爭議、會議各方各說各話，或需要協助他人推進想法時。

1. 請對方提出一個具體例子，再問「這個例子代表的共通概念是什麼？」
2. 邀請對方定義關鍵詞，接著共同找一個可能的反例，確認定義邊界。
3. 找出一個對方也認同的相關主張，檢查它是否與原論點矛盾；先讓對方確認你的理解。
4. 必要時用對方熟悉的類比說明，再指出類比的相同處和不相同處。
5. 整理目前較穩健的暫定定義、仍未解決的例外與下一個問題。

**成果檢查：**對話後的概念比開始時更精確；對方認可你忠實呈現其立場；類比沒有取代證據。

## 個人思考習慣連結

- **主習慣｜#4 #問對問題：確保解決的是真正的問題。**【逐字稿明示】四步提問法先追問例子背後的概念與價值。自我檢查：我是否從表面情境追到真正爭論的概念？
- **輔助｜#47 #受眾：考慮溝通對象的特性與其在乎的事。**【逐字稿明示】類比效果取決於聽眾是否熟悉。自問：對方能理解我的例子嗎？
- **輔助｜#21 #邏輯謬誤：辨認推理中的錯誤結構。**【延伸建議】反詰前確認命題一致；自問：我發現的是實際矛盾，還是把兩個不同情境硬湊在一起？

## 核心概念延伸

【一般策略／推論】使用「鋼人化後提問」：先用最強、最公平的方式重述對方主張，請對方確認，再分別測試定義範圍、反例與前提一致性。這能降低稻草人風險，讓提問更像共同研究而不是交叉盤問。

## Notion 行動卡

- **情境：**挑一場即將發生、涉及抽象價值詞的對話。
- **下一步：**預備一個概念問題、一個反例和一個對方熟悉的類比；現場先重述確認。
- **完成證據：**會後記錄原始定義、修正後定義、未解例外及對方回饋。
- **回顧問題：**哪個問題最有助釐清？我有沒有把「提問」用成施壓？

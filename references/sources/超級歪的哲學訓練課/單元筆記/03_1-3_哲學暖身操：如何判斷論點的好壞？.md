# 哲學暖身操：如何判斷論點的好壞？

來源：超級歪的哲學訓練課！帶你破解人性盲點，養成邏輯腦｜第 1 章・單元 3｜原始逐字稿未收錄於本 repo

## 精華摘要

- 判讀論證先拆出前提與結論，再檢查命題能否判真偽、推理形式是否支持結論、前提是否可信，以及證據是否足夠且平衡。
- 有效推理與健全論證不同：推理形式有效，不保證前提是真的；還要檢查前提與證據。
- 要留意隱藏前提、選擇性呈現證據和離題轉移，也要願意在新證據出現時修正自己的看法。

## 關鍵概念

- **事實、意見、論點**：逐字稿以可觀察內容、主觀信念和由前提支持的結論作區分。真實討論中有些陳述兼含事實判斷與價值判斷，需拆成可查證子主張，不能只貼一個標籤。
- **前提與結論**：把話改寫成「因為 A，所以 B」可先找出理由和欲證明的主張，但自然語言可能有多個隱藏前提。
- **命題與可判定性**：若主張模糊到無法說明什麼觀察會支持或反駁，就難以進行有效檢驗。
- **有效與健全**：形式有效表示若前提為真，結論會跟著成立；健全還要求前提為真。論證說服力另需看證據品質與反方材料。
- **選擇性偏誤／離題**：只呈現有利證據會扭曲判斷；用另一個議題類比，未必回答原議題。

## 可複製的行動／能力

**適用情境：**評估一則新聞、提案、AI 回答、廣告或會議中的重要主張。

1. 用一句話寫出對方真正要你相信或採取的結論。
2. 列出每個前提，標記明示／隱藏，以及可查證／價值判斷。
3. 檢查推理：即使前提都成立，結論是否必然或合理地推出？有沒有跳步、矛盾或離題？
4. 逐項查核關鍵前提的來源，並主動搜尋反例、反方證據或替代解釋。
5. 根據證據強弱調整結論語氣與信心，寫下什麼新資料會使你改變看法。

**成果檢查：**論證圖能讓他人看見前提與推論；最關鍵的事實前提可追溯來源，反方證據沒有被刻意略去。

## 個人思考習慣連結

- **主習慣｜#21 #邏輯謬誤：辨認推理中常見的非形式錯誤。**【逐字稿明示】本篇直接教前提、結論、有效性、健全性與混淆視聽。自我檢查：我是在回應原論點，還是被類比、情緒或轉題帶離？

- **輔助｜#23 #來源品質：評估資訊來源的可靠性。**【延伸建議】核對證據的來源與脈絡；自問：來源是否直接支持這個精確主張？

## 核心概念延伸

【一般策略／推論】用一頁式「論證拆解卡」建立可重用流程：結論 → 前提 → 隱藏假設 → 推理連接 → 來源 → 反證／替代解釋 → 暫定信心。遇到高影響決策，請另一人只挑戰最弱前提，降低自己只替既有立場找證據的風險。

## Notion 行動卡

- **情境：**挑一個正在流傳、會影響你決策的主張。
- **下一步：**完成論證拆解卡，先查最關鍵的一項前提，再找一項相反證據。
- **完成證據：**論證圖、來源連結、反方材料及更新後的信心／結論。
- **回顧問題：**哪個前提最脆弱？若它為假，結論還站得住嗎？

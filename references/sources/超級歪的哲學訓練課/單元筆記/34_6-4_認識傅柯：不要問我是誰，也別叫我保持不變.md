# 認識傅柯：不要問我是誰，也別叫我保持不變

## 精華摘要

- 傅柯延續尼采的系譜學，追問「正常／異常」「罪犯」「性傾向」等知識分類如何在歷史中形成，以及它們如何影響機構對人的處置。
- 身分標籤不只是自我描述，也可能連結醫療、教育、法律與國家制度的分類權力；回顧歷史可看見分類並非永恆不變。
- 本篇是人物導讀，傳記、運動經歷與制度史主張未附原始來源；不要把「標籤有權力效果」簡化成所有標籤都沒有用或都應拒絕。

## 關鍵概念

- **知識與權力相連**：分類知識會影響誰被視為正常、需要矯治、應受監禁或可被接納；權力也可能透過日常制度運作，而不只來自單一壓迫者。
- **歷史偶然性**：某些身分與疾病分類在特定歷史條件下形成，後來被視為自然常態；理解其生成不等於否認當事人的實際經驗。
- **機構作為分類場域**：學校、醫院、法院、監獄等可能同時提供照護／服務與行為分類／管理，需具體分析其功能和後果。
- **持續生成的自我**：傅柯的觀點鼓勵人不被單一身份定義；但自我認同標籤也可能提供社群、法律保障與自我理解，應由當事人決定是否使用。

## 可複製的行動／能力

**適用情境：**遇到一種被當成理所當然的身分分類、校園／職場標籤或制度判定時。

1. 寫明標籤由誰定義、用什麼標準、在哪個制度情境中使用。
2. 追溯這套分類何時出現、曾如何變化，以及受分類者是否參與定義。
3. 分析分類帶來的具體效果：取得服務／保障、污名／排除、資源分配或自我理解。
4. 尋找當事人自己的描述與替代方案，避免由旁觀者替他們決定是否要標籤。
5. 若要改制度，提出兼顧可用資料、權益與自願性的修正方式。

**成果檢查：**能說清分類權力如何運作、誰受益／承擔成本，並區分制度批判與否認個人需求。

## 核心概念延伸

【一般策略／推論】畫「分類—權力—結果」圖：規則／知識 → 執行機構 → 被分類者 → 得到的服務與限制 → 可申訴／修訂機制。再向受影響者確認圖是否準確，避免只從制度管理者角度理解分類。

## Notion 行動卡

- **情境：**一項最近被使用、且影響你或他人待遇的身分標籤。
- **下一步：**追溯標準制定者、歷史變化、實際效果及申訴管道。
- **完成證據：**制度來源、受影響者回饋、分類效果圖與一項改善提案。
- **回顧問題：**這個標籤提供了什麼支持，又帶來哪些限制？使用與否是否由當事人選擇？

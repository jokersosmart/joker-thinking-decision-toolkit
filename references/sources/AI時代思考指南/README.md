## 來源與查核邊界

課程索引中的原課堂網址可作為來源追蹤入口。若補充資料引用統計、人物案例、研究結果、方法名稱或其他外部事實，應依 `references/reports/待驗證事項.md` 的規則另行查核。補充資料的主要用途是保留思考角度與操作示例，而不是取代外部事實查證。

# 5-3 Case02 — Coverfox：月燒 110 萬，你要救它還是收掉？

來源：AI 超級大腦課｜單元 5-3｜原始逐字稿未收錄於本 repo

## 精華摘要

- 案例處境：學員扮演 2020 年疫情封城期間剛接任兩個月的 Coverfox（印度線上保險比價公司）執行長，公司每月支出遠高於收入，現金只夠撐不到一年，投資人不再加碼，董事會要求兩週內拍板。
- 要做的決策：在三條路中選擇或組合——A 降本求生（裁員、砍半燒錢速度）、B 業務轉型（把比價與佣金結算系統改賣給銀行等企業）、C 賣斷收場（接受對手的收購報價）。
- 本單元只出題，不給答案；講師提醒每條路都要回答後續的難題，例如 A 如何對員工說明、B 團隊能否撐過驗證期、C 留下的客戶怎麼辦。

## 關鍵概念

- **現金跑道**：用「每月淨流出」對照「帳上現金」推算還能撐多久，是評估三條路的共同起點。【內容推論】
- **結構性墊款缺口**：代理人佣金當天付出、保險公司款項延後一個半月才入帳，代理人越多、公司要先墊的錢越多，成長反而加重現金壓力。【逐字稿明示】
- **燒錢買成長的失效**：前任經營者持續擴編，但人力成本增幅遠大於收入增幅（具體百分比【待驗證】）。【逐字稿明示】
- **四重壓力疊加**：燒錢失控、墊款結構、投資人退場、疫情衝擊同時發生，使「再等等看」不再是選項。【逐字稿明示】
- **案例數字**：月燒 110 萬美元、月收 62 萬美元、員工近千人、累計募資、1 億美元收購報價等皆為課程敘述【待驗證】。

## 可複製的行動／能力

**適用情境：**組織或個人現金正在流失、必須在「縮減、轉型、退出」之間限時做決定，而手上只有幾個粗略數字時。（解析見下一單元）

1. 先把現況寫成三個數字：帳上現金、每月流入、每月流出，算出不改變任何事時還能撐幾個月。
2. 把每條路徑對現金流入與流出的影響分別寫成假設（例如砍掉多少支出、新收入何時出現）。
3. 為每條路徑估出未來 12–24 個月的現金水位，標出最低點與何時觸底。
4. 列出每條路徑最大的未知數與代價（人才流失、驗證期、品牌消失）。
5. 用 AI 陪練或同伴挑戰自己的假設，再決定單選或組合。

**成果檢查：**能說出每條路徑「還能撐多久、最壞落在哪裡、靠哪個假設成立」，而不是只憑對大數字的直覺選邊。

## 個人思考習慣連結

- **主習慣｜#26 #估計：進行合理的估計。**【內容推論】下一單元標題以估計為核心；本案的缺口是決策者只看到「月燒 110 萬」的驚嚇數字，尚未把三條路換算成可比較的現金跑道。自我檢查：我能把每條路的跑道拆成可被挑戰的假設嗎？
- **輔助｜#13 #相關性：分析變數之間的相關關係。**【內容推論】過去「多花錢、收入也多」的現象，是否真代表擴編帶來收入，需要先釐清才能判斷該不該延續舊打法。自我檢查：支出與收入一起上升，背後有沒有其他共同推動的因素？

## 核心概念延伸

【一般策略／推論】限時的存亡決策最容易被兩種數字綁架：嚇人的虧損數字讓人急著退出，好聽的收購金額讓人以為退出很划算。先把三條路都換算成同一把尺（現金水位隨時間的變化），再談偏好與風險承受度，比較不會被單一數字牽著走。但估算只能支撐判斷，不能取代對團隊執行力、市場接受度等質性因素的評估；也不宜在資料極度缺乏時把粗估當成精確預測。

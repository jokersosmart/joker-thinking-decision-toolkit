# 思考習慣情境搭配網

> 建立日期：2026-10-14｜資料來源：AI 時代思考指南（45 單元筆記）、超級歪的哲學訓練課（51 單元筆記）、AI 超級大腦課（45 篇單元筆記）。各課程的逐字稿原文不收錄在本 repo（AI 時代思考指南除外）。
> 地位：**應用層**，排在 v3 正式定義之後、情境報告之前。這裡只記錄「哪些習慣在什麼情境下一起出現」，不改寫任何 v3 定義。

## 為什麼需要這張網

77 個習慣是**節點**，搭配是**邊**，**情境決定這次要啟用哪幾條邊**。同一個主習慣，換了情境，搭配的輔助習慣就會換。例如 #23 來源品質：檢查研究說法時要配 #46 可複製性，檢查 AI 生成的影音時要配 #29 可驗證性，檢查權威的價值主張時要配 #27 詮釋視角。

使用方式：
1. 依 v3 選定主習慣後，先到本檔「情境轉化表」找主習慣，比對目前情境，選出 0–2 個輔助習慣。
2. 若需要案例依據，再到「單元搭配明細」找相近情境的單元，點連結讀單元筆記。
3. 找不到相近情境時，以「轉化軸」自組搭配，並標明為「自組」。

## 證據等級

| 標記 | 意思 |
|---|---|
| 逐字稿明示 | 課程逐字稿直接講到這個方法，筆記作者把它對應到這個習慣 |
| 課程方法明示 | 課程明確提出的方法，對應到習慣是個人連結 |
| 內容推論／個人連結推論／延伸建議 | 由內容推出來的連結，課程沒有直接這樣說 |
| 待驗證 | 連結或背後的事實主張還需要查證 |
| 逐字稿提及 | 該習慣名稱在逐字稿中出現 2 次以上；只代表有被提到，搭配強度最弱 |

本檔的「情境轉化表」與「轉化軸」是把上述單元連結**彙整後的推論**，不是課程原話。

## 轉化軸：決定搭配的四個情境變數

| 轉化軸 | 判斷問題 | 傾向啟用的習慣群 |
|---|---|---|
| 檢查對象 | 這次在檢查的是**主張**、**人**、**系統**，還是**自己**？ | 主張 → #19 #23 #29 #21；人 → #47 #70 #73 #68；系統 → #60 #65 #62 #64；自己 → #75 #6 #74 |
| 所在階段 | 正在**定題**、**驗證**，還是**推動／規模化**？ | 定題 → #4 #1 #10 #31；驗證 → #29 #19 #37 #5；推動 → #33 #68 #53 #46 |
| 資料狀態 | 有沒有數據？數據完不完整？ | 有數據 → #5 #13 #12 #14；不完整 → #26 #3 #37；只有轉述 → #23 #46 |
| 風險與可逆性 | 錯了能不能撤回？誰承擔後果？ | 可逆 → #37 #29 小試驗；不可逆或影響他人 → #57 #59 #8 #6 #74 |

# 思考決策資料庫

這個資料庫現在包含三個互補層級：`思考習慣清單_v3.md` 是 76 個思考習慣的核心知識本體；`思考習慣補充集_AI時代思考指南.md` 保存新的逐字稿所提供的不同角度、例子與操作變體；45 篇課程逐字稿轉換成的決策報告則是可重複使用的**情境應用流程**。每份報告不是單一標籤，而是把習慣組合到特定問題中的「組合拳」；報告與補充集內的核心、輔助、隱性或候選標籤只代表局部應用，不能覆寫 v3 的正式定義。

## 如何使用

1. 先讀 `思考習慣清單_v3.md` 的分類與相關習慣，辨識目前問題的主要思考能力；必要時讀取該習慣的操作型定義與檢查清單。
2. 若需要不同角度、例子、類比、操作步驟或限制條件，再讀 `思考習慣補充索引_AI時代思考指南.md` 與補充集；重複但不同的變體應保留。
3. 只有在需要現成案例流程、產出格式、跨領域遷移或情境停損條件時，才從下方索引選出最接近的 0–1 份主要報告，必要時加不超過 2 份互補報告。
4. 先讀報告中的「一句話判斷」與「適用情境」，確認它真的符合目前處境，而不是只共享表面名詞。
5. 依「決策流程」逐步產出答案，不要跳過進入下一步的判準。
6. 用「常見誤用與停損條件」檢查是否需要修正或停止；若補充集、報告與 v3 或目前問題衝突，以 v3 與實際問題為優先。
7. 若沒有高度匹配報告，直接依 v3 與補充集建立「自組流程」；若情境不同，從「跨領域遷移」取得結構，不要照抄原案例。

## 證據標記

- **明示**：逐字稿直接點名或清楚定義該思考習慣。
- **推論**：逐字稿實際使用了該習慣的操作，但沒有直接命名。
- **待驗證**：有合理跡象，但現有內容不足以確定。
- **一般策略**：有助於流程，但不屬於《思考習慣清單》的 76 個正式習慣。

## 對話使用方式

描述問題時，至少提供「想達成的結果、目前限制、已知證據、可接受代價」。可使用以下提示：

> 請先從《思考習慣清單_v3》辨識這個問題的主要思考習慣與必要的輔助習慣，再視需要讀取逐字稿補充集取得不同角度與例子，最後才找 0–1 份主要情境報告與不超過 2 份互補報告；請說明 v3 負責的思考缺口、補充集提供的變體、報告能協助的落地流程，以及還缺少哪些證據。

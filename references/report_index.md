# 決策報告快速索引（45 份）

用「處境訊號」而不是單一關鍵字配對。先選最接近的 1–3 份報告，再讀取對應全文；不要一次載入或套用全部報告。若沒有高度匹配，改用 Skill 主規則的通用決策協定並標明「自組流程」。

## 配對順序

1. 比對使用者描述與「適用訊號」的重疊程度。
2. 用「一句話判斷」檢查是否真正回答當前困境，而非只共享表面名詞。
3. 檢查利害關係人、風險、可逆性與所需產出是否一致。
4. 最多選 3 份：一份主報告，加上不超過兩份互補報告；若只是寫作、翻譯或簡單查詢，保持輕量，不啟動完整流程。

## 共同主鏈

> 定義真正問題 → 明確目標、限制、證據與可接受代價 → 拆解變數／利害關係人 → 產生可比較選項 → 設計最小可逆驗證 → 依結果擴大、修正或停損。
